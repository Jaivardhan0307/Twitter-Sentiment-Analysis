# Twitter Sentiment Analysis

A simple and effective **Sentiment Analysis** project using Twitter data. This project classifies tweets into **Positive or Negative** categories using Natural Language Processing (NLP) and Machine Learning.

## 📊 Dataset
- **Source**:[ [Kaggle - Sentiment140 Dataset](https://www.kaggle.com/datasets/kazanova/sentiment140)](https://www.kaggle.com/datasets/jp797498e/twitter-entity-sentiment-analysis)
- **Note**: The dataset is **not included** in this repository due to its large size (1.6 million tweets). Please download it directly from the Kaggle link above to run the code.

## 🚀 Features
- Text preprocessing (removing URLs, mentions, punctuation, and stopwords)
- TF-IDF Vectorization
- Logistic Regression Classification
- Model Evaluation (Accuracy & Confusion Matrix)
- WordCloud Visualizations for positive and negative terms

## 📈 Results
- **Accuracy**: ~80% *(Note: Replace this with your actual model accuracy!)*
- Successfully classifies unseen text with a high degree of reliability.

## 🛠️ Technologies Used
- **Language**: Python
- **Libraries**: Pandas, Scikit-learn, NLTK, Matplotlib, Seaborn, WordCloud
- **Environment**: Google Colab

## 💡 How to Run the Project
1. Download the dataset from the Kaggle link above.
2. Open the `Twitter_Sentiment_Analysis.ipynb` file in **Google Colab**.
3. Upload the dataset directly into the Colab environment.
4. Run all cells sequentially.
